# Documentation revision history

<table data-first-column-sticky><thead><tr><th width="98.7066650390625">Version</th><th>Description of changes</th></tr></thead><tbody><tr><td>6.0</td><td><ul><li><strong>New WEKA CLI (wekactl)</strong>: Manage WEKA clusters from any supported platform using a new <code>weka</code> CLI (formerly <code>wekactl</code>), a modern command-line interface and Go API. <a href="../getting-started-with-weka/weka-cli-overview/">>></a></li><li><strong>Asynchronous replication</strong>: Protect your data with asynchronous replication, which synchronizes filesystems directly between two NeuralMesh clusters. >></li><li><strong>Async delete</strong>: Remove large files, directories, and symlinks with async delete, without keeping client processes blocked on recursive delete work. <a href="../best-practice-guides/async-delete.md">>></a></li><li><strong>NFS multi-tenancy</strong>: Give tenants NFS access without installing a client. Each tenant gets isolated client groups and exports, reached through dedicated floating IP addresses in its own network space. Kerberos, ACLs, NFS group resolution through LDAP, and NFSv3 locking remain available only in the root organization, and tenant mounts use <code>sec=sys</code> with numeric UIDs and GIDs. <a href="../operation-guide/weka-native-multi-tenancy-management/manage-nfs-for-tenants.md">>></a></li><li><strong>SMB external LDAP POSIX resolution</strong>: Resolve SMB POSIX user and group attributes from an external LDAP directory, separately from the domain used for authentication. <a href="../additional-protocols/smb-support/smb-external-ldap-posix-resolution.md">>></a></li><li><strong>Diagnostics data management</strong>: Manage diagnostics data for clusters, servers, and containers from the CLI, including collection, listing, and removal. <a href="../support/diagnostics-management/diagnostics-data-management.md">>></a></li><li><strong>Traces debug level management</strong>: Set and inspect trace debug levels alongside the protocols debug levels, from either the CLI or the GUI. <a href="../support/diagnostics-management/traces-and-protocols-debug-level-management/">>></a></li><li><strong>Breaking changes</strong>: Review the changes that take effect immediately after upgrading, including six NFS CLI subcommands renamed from <code>delete</code> to <code>remove</code> (the legacy spellings are kept as aliases), tightened role requirements on five NFS API endpoints, and renamed JSON output keys. <a href="../operation-guide/upgrading-weka-versions/breaking-changes.md">>></a></li><li><strong>View alerts as a tenant</strong>: Cluster administrators can view the alert list as it appears to a specific tenant admin, without logging in as that user. This helps when investigating alert visibility discrepancies in multi-tenant clusters. <a href="../operation-guide/weka-native-multi-tenancy-management/multi-tenancy-cluster-level-administration.md#view-alerts-as-a-tenant">>></a></li><li><strong>GUI updates</strong>: Explore the refreshed management UI with a new look and feel. <a href="../getting-started-with-weka/manage-the-system-using-weka-gui.md">>></a></li></ul></td></tr></tbody></table>
