# WEKA Operator day-2 operations

Day-2 operations for clusters managed by the WEKA Operator include observability and monitoring, hardware maintenance, cluster scaling, and cluster maintenance. These procedures follow the WEKA Operator version line, and the documentation covers all supported WEKA versions in one place.

To operate a cluster running WEKA 4.4, see [Monitor, scale, and maintain the cluster](https://docs.weka.io/kubernetes/weka-operator-day-2-operations).
