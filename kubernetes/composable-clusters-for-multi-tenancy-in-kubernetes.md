# Composable clusters for multi-tenancy in Kubernetes

Composable clusters run multiple independent WEKA clusters on shared hardware. The WEKA Operator assigns each cluster a dedicated set of Kubernetes nodes, drives, cores, and memory, so tenants keep full resource isolation.

Composable clusters are deployed with the WEKA Operator, and their documentation follows the Operator version line.

For the concept, placement rules, and deployment options, see [Composable clusters for multi-tenancy in Kubernetes](https://docs.weka.io/kubernetes/composable-clusters-for-multi-tenancy-in-kubernetes).
