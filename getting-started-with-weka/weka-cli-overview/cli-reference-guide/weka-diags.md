# weka diags

Understand the status of the cluster and its environment.

```sh
weka diags
```

## weka diags collect

Collect diags from all cluster containers to a directory on the container running this operation.

```sh
weka diags collect
```

## weka diags list

Print results of a previously collected diags report.

```sh
weka diags list
```

## weka diags rm

Stop a running instance of diags, and cancel its uploads.

```sh
weka diags rm
```

## weka diags upload

Collect and upload diags from all cluster containers to Weka's support cloud.

```sh
weka diags upload
```
