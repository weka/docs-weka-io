# weka completion

Emit, install or remove autocompletion support for this utility.

```sh
weka completion
```

## weka completion all

Completion support for Bash, Zsh, and fish.

```sh
weka completion all
```

### weka completion all install

Install completion support for Bash, Zsh, and fish.

```sh
weka completion all install [--directory <string>] [--filename <string>] [--no-descriptions]
```

| Parameter               | Description                       |
| ----------------------- | --------------------------------- |
| `--directory` \<string> | Install into the named directory. |
| `--filename` \<string>  | Use the given filename.           |
| `--no-descriptions`     | Disable completion descriptions.  |

### weka completion all uninstall

Uninstall completion support for Bash, Zsh, and fish.

```sh
weka completion all uninstall [--directory <string>] [--filename <string>]
```

| Parameter               | Description                       |
| ----------------------- | --------------------------------- |
| `--directory` \<string> | Install into the named directory. |
| `--filename` \<string>  | Use the given filename.           |
