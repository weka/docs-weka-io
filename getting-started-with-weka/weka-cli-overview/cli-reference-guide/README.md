## Common options

These options are common to most commands and are omitted from the individual command descriptions on the command group pages.

### Connection options

| Parameter                       | Description                                                                                                                                                                                                |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--CONNECT-TIMEOUT` \<duration> | Timeout for connecting to cluster.                                                                                                                                                                         |
| `-S`, `--CONTAINER` \<string>   | Local container. Connect the named container running on this system.                                                                                                                                       |
| `-H`, `--HOST` \<string>        | Connect to this host. Alternatively, use the WEKA\_HOST env variable.                                                                                                                                      |
| `-P`, `--PORT` \<uint16>        | Connect to this TCP port. Alternatively, use the WEKA\_PORT env variable.                                                                                                                                  |
| `-T`, `--TIMEOUT` \<duration>   | Timeout to wait for response.                                                                                                                                                                              |
| `--auto-accept-cert`            | Auto accept certificates. Skip confirming first certificate from unknown server. Alternatively, use the WEKA\_AUTO\_ACCEPT\_CERT env variable.                                                             |
| `-k`, `--insecure`              | Disable TLS verification. Should only be used if the network is trusted. Alternatively, use the WEKA\_INSECURE env variable.                                                                               |
| `--jump` \<string>              | Tunnel the connection through this SSH jump host, e.g. user@bastion. Uses the system ssh with your existing \~/.ssh/config, known\_hosts, and agent. Alternatively, use the WEKA\_JUMP\_HOST env variable. |
| `--kube-namespace` \<string>    | Kubernetes namespace of the WEKA management service. Alternatively, use the WEKA\_KUBE\_NAMESPACE env variable.                                                                                            |
| `--kube-weka-cluster` \<string> | Reach this WEKA cluster (by name) through kubectl port-forward to its operator-managed management service. Enables Kubernetes mode. Alternatively, use the WEKA\_KUBE\_CLUSTER env variable.               |
| `--kubeconfig` \<string>        | Path to the kubeconfig file for kubectl port-forward. Defaults to kubectl's own resolution (KUBECONFIG / \~/.kube/config). Alternatively, use the WEKA\_KUBECONFIG env variable.                           |

## weka

WEKA Administrative CLI.

```sh
weka [--build] [--check] [--legal] [--licenses] [--opt-in] [--opt-out] [--update] [--version]
```

<table><thead><tr><th width="158.12109375">Parameter</th><th>Description</th></tr></thead><tbody><tr><td><code>--build</code></td><td>Prints build information and exits.</td></tr><tr><td><code>--check</code></td><td>Reports whether a newer CLI has been released, without offering to install it.</td></tr><tr><td><code>--legal</code></td><td>Prints software license information and exits.</td></tr><tr><td><code>--licenses</code></td><td>Prints third-party license information and exits.</td></tr><tr><td><code>--opt-in</code></td><td>Opt in to the new CLI. Replaces /usr/bin/weka.</td></tr><tr><td><code>--opt-out</code></td><td>Opt out of the new CLI. Restores /usr/bin/weka.</td></tr><tr><td><code>--update</code></td><td>Checks whether a newer CLI has been released, and offers to install it.</td></tr><tr><td><code>-v</code>, <code>--version</code></td><td>Prints the CLI version and exits.</td></tr></tbody></table>
