# WEKA CSI Plugin

The WEKA CSI Plugin connects Kubernetes worker nodes and the control plane to WEKA clients. It provides static and dynamic volume provisioning, volume expansion, snapshots, and quota enforcement. The plugin runs standalone or embedded in the WEKA Operator.

The WEKA CSI Plugin has its own version line. Its documentation covers all supported WEKA versions in one place, and its interoperability section lists the supported Kubernetes and WEKA versions.

To deploy or configure the WEKA CSI Plugin with a cluster running WEKA 4.4, see [WEKA CSI Plugin](https://docs.weka.io/appendices/weka-csi-plugin).
